Paper Definitions:
Paper definition files must be in a comma separated values (CSV) format and the columns must be in the following order

Category, PaperID, Paper Name, Details, Finish, Colour, M Weight, Weight, Calliper, Sheet Width, Sheet Height, Supplier, Double Sided Paper (Y/N), Can be Cut into Smaller Sheets (Y/N), Has mulitple parts (# of Parts) , Perfecting (Y/N), Scoring Required (Y/N), Sort Order, Recommendations
First, select a file containing your new database in CSV format. Then click on the import button.
Clicking on the export button will download the current paper definitions in CSV format.
You can then open this in a spreadsheet program such as Microsoft Excel.
