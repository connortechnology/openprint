Import/Export Price List
Price list files must be in a comma separated values (CSV) format and the columns must be in the following order:

ServiceID, EquipmentID, Min, Max, Units, Service Cost, Service Markup, Service Sale Price, Discountable

The columns should have titles. The first row of data will be treated as column titles, and hence will be ignored.

Clicking on the export button will download the current price list in CSV format.
You can then open this in a spreadsheet program such as Microsoft Excel.
