Import/Export

Colour definition files must be in a comma separated values (CSV) format and the columns must be in the following order:

PMSID, ServiceID, MaterialID, Colour Name, Washes, Equipment, Service Cost, Service Markup, Material Cost, Material Markup

Click here to view an example of data in CSV format.

First, select a file containing your new database in CSV format. Then click on the import button.

Clicking on the export button will download the current colour definitions in CSV format.
You can then open this in a spreadsheet program such as Microsoft Excel.
