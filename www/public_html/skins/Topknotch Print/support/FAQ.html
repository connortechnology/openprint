Frequently Asked Questions


How do I check the production status of my order?

Select order history and click on the appropriate order ID. Clicking on a project name will reveal the current status of all the individual services included in that project.

How can I change the specifications of an order that I have placed?

You must contact directly via e-mail or by phone at 905-624-5100 or 1-866-382-5100. This is because your order may have already entered the production stage.

File Upload Instructions

  • File formats accepted: PDF, JPG, TIF and EPS.
  • File must be at least 300 DPI (dots per inch) for best printing results, otherwise the print will not be sharp and will appear grainy.
  • When creating PDF files using InDesign or other software, choose the "Press Quality" setting.
  • For calendars, magazines, manuals, newsletters, and any other multi-page documents, please upload one multi-page PDF. Do not upload each page separately. However, if the cover is to be printed on a different paper than the rest of the document, please provide one multi-page PDF file for the cover, and one multi-page PDF file for the rest of the pages. The PDF pages for each multi-page PDF file must be in the right sequence (cover page is page one, inside cover is page two, etc.).
  • For designs with bleeds use not less than 0.25 inches bleeds.
