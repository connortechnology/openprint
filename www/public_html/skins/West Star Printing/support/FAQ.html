How do I check the production status of my order?
Select Order History and click on the appropriate order ID, then click on a project name which will then reveal the current status of all the services included in that project.

How can I change the specifications of an order that I have placed?
Once an order has been placed only one of our representatives can cancel the order. A new order can then be created with a new project and specifications. To contact a representative please use our help desk.
