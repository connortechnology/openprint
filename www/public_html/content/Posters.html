There are three different menthods of printing posters.

1. Short run digital upto 12" x 18", run lenghts upto 1000; usually printed on 100lb gloss text

2. Short run inkjet upto 42 inches wide by 100 feet long on our Epson 9800. Please call for pricing for inkjet posters

3. Offset printed posters upto 27" x 39.5". Movie posters are normally done using this process on 80lb or 100lb gloss text
